# Ginna's Portfolio

## About My Website

This is my personal portfolio website. I created it to share a little about myself, the projects I have worked on, and some of my favorite things.

## What I Used

- HTML
- CSS
- JavaScript
- Formspree
- GitHub Pages

## Accessibility

I tried to make my website easy for everyone to use. I added alt text to my images, labels to my contact form, and buttons that can be used with a keyboard. I also made the pages responsive so they can work on different screen sizes.
